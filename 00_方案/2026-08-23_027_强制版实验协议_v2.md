# 027 强制版实验协议 v2

## 1. 固定实验架构
成熟SOTA基线 + 真实失效机制 + 2个独立小模块 + 三数据集跨域验证。

## 2. 成熟SOTA基线
- 主干：复用成熟 Vision Transformer / token routing 骨干。
- 禁止用理论 FLOPs 替代真实 GPU 延迟比较。

## 3. 失效机制（真实可复现）
静态稀疏率忽略样本难度异质性，导致：
1. easy样本计算浪费；
2. hard样本计算不足；
3. 延迟预算下性能退化。

## 4. 两个独立模块
### 4.1 Module A: Difficulty-Aware Router
- 目标：仅估计难度路由权重。

### 4.2 Module B: Uncertainty Budget Allocator
- 目标：仅按不确定性分配 token/算力预算。

## 5. 三数据集跨域验证
- 源域：CIFAR-100
- 目标域：工业视觉/异常检测数据
- 外部域：CIFAR-100-C 或扰动场景

## 6. 强制实验矩阵
- C1：Baseline Dense
- C2：+Module A only
- C3：+Module B only
- C4：Full A+B

## 7. 主指标
- 主终点：相同 P95 延迟预算下 accuracy
- 次终点：hard-set accuracy、token保留率、显存、能耗代理

## 8. 完备性实验
- 模块消融
- 延迟预算敏感性
- 困难样本集合稳健性
- 多种子复现
- 资源审计
- failure case 可视化

## 9. 结论约束
若仅平均样本有效而 hard-set 无改善，不得宣称可靠效率收益。

## 10. 可复现要求
保存：batch、GPU型号、warmup、timer代码、路由日志、P95计算脚本、指标 json。
