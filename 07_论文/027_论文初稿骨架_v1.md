# 027 论文初稿骨架 v1

## 暂定题目

Risk-Aware Dynamic Token Inference for Latency-Constrained Visual Recognition

中文：面向延迟约束视觉识别的风险感知动态 Token 推理

## 论文定位

应用型高效视觉推理论文。核心问题不是宣称动态稀疏一定超过 Full，而是研究：在有限真实 GPU 延迟预算下，输入难度与预测不确定性是否能指导更合理的 Token 计算分配，尤其是在困难或异常样本上。

## 章节骨架

### 1 Introduction

边缘视觉系统同时面对延迟预算和样本难度不均衡问题。固定稀疏策略不能区分简单与困难样本；仅使用单一难度或不确定性信号也可能产生不稳定路由。本文提出 RATA，并用 clean CIFAR-100 机制实验和工业视觉应用实验检验其真实收益边界。

### 2 Related Work

动态 Token 推理、稀疏注意力、风险/不确定性估计、工业异常检测。每一类工作结尾说明：已有工作通常缺少统一的真实 P95 延迟、困难样本分层和路由消融分析。

### 3 Method

介绍输入级 difficulty 分支、uncertainty 分支、联合路由分数、Token 选择和稀疏注意力 kernel。符号必须与 `rata_vit.py` 和 `sparse_attention.py` 一致。

### 4 Experimental Setup

数据集、固定划分、训练步数、六种方法、seed、延迟测量、指标和统计方法。明确 CIFAR-100-C 未进入当前正式结果。

### 5 Results

5.1 clean CIFAR-100 主结果；5.2 应用数据结果；5.3 困难/异常样本分层；5.4 门控消融；5.5 延迟与 Token 保留率。

### 6 Limitations

当前 RATA 在 clean CIFAR-100 上没有超过 Full，路由开销会抵消部分稀疏收益；应用数据结果若不能证明困难样本收益，则把贡献收缩为系统性验证分析。

### 7 Conclusion

只总结数据实际支持的结论，不把理论 FLOPs 或单一数据集收益外推为通用部署收益。
