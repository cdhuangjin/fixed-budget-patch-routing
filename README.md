# Fixed-Budget Patch Routing

Source code, runnable configuration, and experimental data for fixed-budget patch routing.

- `02_代码/`: implementation, evaluation scripts, and tests.
- `03_配置/`: experiment configuration.
- Where present, CSV and JSON files contain experimental results and data manifests.
- Original third-party datasets are not bundled; obtain them from their respective providers.

Some scripts use local data paths. Configure those paths before running experiments.
